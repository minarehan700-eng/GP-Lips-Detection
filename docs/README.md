## Quick start

1. Read the dissertation in `LIPS_OFFLINE_DISSERTATION.md`.
2. Fill in `[Student Name]`, `[Supervisor Name]`, and `[University Name]` on the cover.
3. Connect your Android phone, run the app once, then run `capture_screenshots.ps1` if any figures need updating.
4. Paste the Markdown into Word (or use Pandoc) for final submission.
